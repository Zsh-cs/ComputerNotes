# JavaSE

语言：中文/[英文](README.md)



本文件夹下主要记录了我通过黑马程序员的“20天精通Java”教学视频自学的JavaSE知识。（链接：https://www.bilibili.com/video/BV1Cv411372m/?spm_id_from=333.337.search-card.all.click）

其实在2024年我就已经看过这套教学视频，但那时只是一览而过，没有做详实的笔记，导致脑海中没有形成完整的JavaSE知识体系，日后深入学习Java后端开发的时候基础不牢，理解一些代码有困难。因此在今年我重新开始看起这套教学视频，并使用`Typora`做了系统性的`Markdown`笔记。尽管这花费了我大约一个月的时间，但我坚信，成为一名优秀的软件工程师不能好高骛远，必须打好扎实的编程基础，否则虽然“走得快”，但是“走不远”！

这本笔记总共分为12个章节，涵盖了JavaSE的所有重要且必须牢固掌握的基础知识：

+ 01-Java for Beginners(Java入门)
+ 02-OOP(面向对象编程)
+ 03-Common APIs(常用API)
+ 04-Exception(异常)
+ 05-Collection Framework(集合框架)
+ 06-File+IO(文件+IO流)
+ 07-Speciall Files+Logs(特殊文件+日志技术)
+ 08-Multithreading(多线程)
+ 09-Network Communication(网络通信)
+ 10-Reflection(反射)
+ 11-Annotation(注解)
+ 12-Dynamic Proxy(动态代理)
