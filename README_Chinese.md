# ComputerNotes

*语言*：中文/[英文](README.md)



在大学本科攻读计算机科学与技术专业的过程中，我通过哔哩哔哩（B站）的很多优质网课，比如黑马程序员的`Java`和`JavaScript`课程、程序员风筑的SpringBoot零基础入门课程、湖科大教书匠的计算机网络课程等等，自学了大量实用且受益终生的计算机知识，我由衷地感谢各位UP主的无私分享，他们是开源精神的实践者！

在自学过程中，我发现学过的东西过一段时间就会遗忘细节和注意事项，而这显然不利于知识的持久化。因此，在简单学习了`Markdown`基础知识后，我萌生了使用`Typora`将自学的重点知识和个人心得记录为`Markdown`笔记的想法，并弘扬那些曾教会我知识的UP主的开源精神，将我的笔记上传到GitHub并开源。

这么做我有两个目的：

+ 方便我个人日后复习和查阅。
+ 希望让更多对计算机有兴趣的初学者能通过我的笔记少走一些弯路。

我将遵循开源精神，致力于不断完善我的笔记，以上。
